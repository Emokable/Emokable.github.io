博客重部署与性能优化记录（2026）

本文由 AI 生成并根据实际操作记录整理，经本人检查后发布。

背景

之前使用的自定义域名因未续费而过期，博客恢复使用 GitHub Pages 默认地址：

https://emokable.github.io/

这次维护的目标是恢复丢失的站点资源和页面，同时把博客重新构建、备份并部署到 GitHub Pages。

这次完成的更新

恢复博客资源

整理并恢复了博客首页封面、文章默认头图、作者头像、网站图标以及文章配图。主页的各个自定义栏目也重新保留，包括关于页、链接页和 Nintendo Switch 页面。

新增 Nintendo Switch 数据页

原来的 Steam 页面改为 Nintendo Switch 游戏记录页：

  • 展示游戏名称、封面、游玩时长、游玩天数和最近游玩日期；
  • 支持按名称、最近游玩时间和游玩时长排序；
  • 数据以静态 JSON 发布，登录凭据不会放入博客；
  • 当前数据由 Nintendo 官方账号导出的历史记录生成。

页面地址：https://emokable.github.io/ns/

后续更新数据时，只需要重新导入本地数据、检查 source/ns/data.json，再重新生成并部署博客即可。

性能优化

本次还做了几项不改变文章内容的优化：

  • 首页文章封面启用懒加载，减少首屏同时请求的图片数量；
  • 修复 NS 页面动态游戏卡片被主题懒加载过滤器替换成占位图的问题；
  • 精简本地搜索索引，只保留标题等必要字段；
  • 删除重复生成的 xml/local-search.xml；
  • 删除 PDF.js 的调试 source map 文件，保留 PDF 阅读器运行所需文件；
  • 移除项目中没有实际使用的构建依赖。

本地检查时，搜索索引由约 1.49 MB 降到约 40 KB，PDF 阅读器本体仍然可用。

移除 PDF 归档页

删除了旧的 /pdf/ 归档页面及顶部菜单入口。文章中已有的 PDF、PPTX 资料和 PDF.js 阅读器资源暂时保留，避免影响旧文章内容。

小结

这次更新完成了域名过期后的站点恢复、文章资源整理、Nintendo Switch 数据页替换、搜索和图片加载优化，并清理了不再使用的 PDF 归档入口。源码和部署流程也重新验证，后续可以按上面的步骤继续维护。
